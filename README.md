# Блог Антона Пасия

Репозиторий дочерней темы сайта https://cl841244-wordpress-53bdv.tw1.ru/. Тема Anton Pasiy наследует Twenty Twenty-Five. Ядро WordPress, родительская тема, база и медиатека здесь не хранятся.

## Структура

```
theme/anton-pasiy/
  style.css            паспорт дочерней темы
  theme.json           колонка, шкала, типографика, контекстные правила
  parts/header.html    липкая шапка: имя сайта и пункт «Блог»
  parts/footer.html    строка копирайта
  templates/home.html  список записей и кнопка «Показать ещё»
  templates/single.html
  templates/404.html
```

Поиск, рубрики и страницы берут шаблоны Twenty Twenty-Five. Шапка и подвал — из этой темы. Своего PHP нет: дополнительные правила лежат в `styles.css` внутри `theme.json` и попадают и на сайт, и в редактор.

## Дизайн-система

Один источник размеров — пресеты `theme.json`. Родительские пресеты `20`–`80` не переопределяются: шапка по-прежнему использует `30` (20px), горизонтальные поля корня — `50`. Новые шаги добавлены рядом.

Шрифт остаётся Manrope из Twenty Twenty-Five: в файле есть кириллица. Код — Fira Code. Колонка 920px.

### Цвет

Палитра родителя. Роли без новых красок:

| Роль | Пресет | Значение |
| --- | --- | --- |
| Фон | `base` | `#FFFFFF` |
| Текст и ссылки | `contrast` | `#111111` |
| Дата, подпись, копирайт | `accent-4` | `#686868` |
| Фон кода | `accent-5` | `#FBFAF3` |

Ссылка в тексте подчёркнута и при наведении становится `accent-4`. Заголовок записи, имя сайта и пункт «Блог» без подчёркивания, пока на них не наведут. Фокус — контур `contrast` с отступом 3px.

### Типографика

| Роль | Размер | Насыщенность | Интерлиньяж |
| --- | --- | --- | --- |
| Текст | 18–20px | 400 | 1.65 |
| H1 | 32–40px | 600 | 1.15, трекинг −0.015em |
| H2 | 24–28px | 600 | 1.25, трекинг −0.01em |
| H3 | 22px | 600 | 1.3 |
| H4 | 20px | 600 | 1.35 |
| H5 | 18px | 600 | 1.4 |
| H6, дата, подпись | 14px | 600 / 400 | 1.4 / 1.45 |

H6 без капители: для кириллицы она шумит. Плавные размеры у текста, H1 и H2; остальные фиксированные.

### Отступы

Шаг 8px, значения в rem. `page` — граница шапки и подвала: от 24px на узком экране до 32px, когда ширины хватает.

| Шаг | Где |
| --- | --- |
| 8 | дата ↔ заголовок, пункты списка, подпись под фото, текст после H3–H6 |
| 12 | заголовок карточки ↔ анонс, текст после H2, абзацы внутри цитаты |
| 16 | абзац ↔ абзац, вертикальные поля цитаты и кода |
| 24 | перед H3–H6; обложка, текст, метки и навигация записи; кнопка «Показать ещё» |
| 32 | перед H2, между публикациями |
| page | шапка → текст, конец текста → строка копирайта |

Перед заголовком места больше, чем после. Зазор один: `blockGap` статьи равен 16px, а правило заголовка его заменяет, а не суммирует. У первого блока статьи верхнего поля нет.

Список публикаций собран так же: внутри карточки 8 и 12px, между карточками 32px.

## Как обновляется тема

WP Pusher ставит тему из подкаталога `theme/anton-pasiy`, ветка `main`. Изменение попадает на сайт после push в `main`. Twenty Twenty-Five должна оставаться установленной: без неё дочерняя тема не работает.

## Где менять оформление

Ширину колонки менять в `theme.json`, в полях `contentSize` и `wideSize`. Новый шаг шкалы — в `settings.spacing.spacingSizes`, затем ссылка `var:preset|spacing|…` в шаблоне или в `styles`. Не заводить отдельную переменную под каждый селектор.

Состав главной, записи и 404 — в `templates/`. Шапку и подвал — в `parts/`.

Кнопка «Показать ещё» реализована плагином **Query Loop Load More**: он обрабатывает атрибуты `loadMore`, `loadMoreText` и `loadingText` блока Query Pagination в `templates/home.html`. Плагин должен оставаться установленным и активным. Ссылка кнопки в теме переведена в `inline-block`: иначе её поле вылезает вверх и съедает отступ от последней записи.

## Зависимости

WordPress с поддержкой блочных тем, установленная Twenty Twenty-Five и активный плагин **Query Loop Load More** для накопительной загрузки записей на главной. Для обновления темы используется WP Pusher.

## Откат

Отменить коммит и отправить `main` на GitHub: WP Pusher поставит предыдущие файлы темы. Чтобы временно вернуть сайт к родительскому виду, в админке активировать Twenty Twenty-Five. Повторная активация Anton Pasiy снова включает файлы этой темы.
